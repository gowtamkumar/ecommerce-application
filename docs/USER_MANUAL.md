## Introduction

Welcome to the E-Commerce Application! This comprehensive platform provides a complete online shopping experience with features for customers, vendors, delivery personnel, and administrators.

### Key Features
- Multi-vendor marketplace support
- Advanced product catalog with variants
- Integrated shopping cart and checkout
- Coupon and discount system

- Multi-currency support
- Real-time notifications

## Customer Guide

### Shopping Cart

#### Adding Items
1. Navigate to a product page
2. Select variant options (size, color, material)
3. Choose quantity
4. Click **Add to Cart**
5. Continue shopping or proceed to checkout

#### Managing Cart
- Click the **cart icon** in the header to view your cart
- Adjust quantities using +/- buttons
- Remove items by clicking the trash icon
- See real-time price calculations with taxes and discounts

### Checkout Process

#### Step 1: Shipping Address
- Select an existing address or add a new one
- Fill in complete address details
- Choose this address for delivery

#### Step 2: Payment Method
- Select payment method:
  - **Cash on Delivery (COD)**
  - **SSLCommerz** (Online Payment)
  - Other configured payment gateways

#### Step 3: Apply Coupons
- Enter coupon code in the **Apply Coupon** field
- Click **Apply** to get discount
- Discount will be reflected in the order summary

#### Step 4: Review & Place Order
- Review order summary
- Check shipping cost
- Verify total amount
- Click **Place Order** to confirm

### Order Tracking

1. Go to **My Account** > **Orders**
2. View all your orders with status
3. Click on an order to see:
   - Order items and quantities
   - Payment status
   - Delivery status and tracking
   - Estimated delivery date

### User Profile

#### Managing Your Profile
- Navigate to **My Account**
- Update personal information
- Change password
- Upload profile picture

#### Shipping Addresses
- Add multiple shipping addresses
- Set a default address
- Edit or delete existing addresses

### Wishlist
- Click the **heart icon** on any product to add to wishlist
- View all wishlist items in **My Account** > **Wishlist**
- Move items from wishlist to cart

## Admin Dashboard

### Accessing the Admin Panel
1. Log in with admin credentials
2. Navigate to `/dashboard`
3. You'll see the admin sidebar with all management options

### Product Management

#### Adding a New Product
1. Go to **Products** > **Add New Product**
2. Fill in product details:
   - Name, description
   - SKU, barcode
   - Price, cost price
   - Stock quantity
   - Categories, brands, tags
3. Upload product images (multiple images supported)
4. Add product variants (size, color, material)
5. Click **Save Product**

#### Managing Variants
- Add size options (S, M, L, XL, etc.)
- Define color variations
- Set material types
- Each variant can have different stock levels and prices

#### Stock Management
- Go to **Inventory** > **Stock Adjustment**
- View current stock levels
- Add or reduce stock quantities
- Set minimum stock alerts

### Order Management

#### Viewing Orders
1. Navigate to **Orders**
2. Use filter dropdown to view by status:
   - Pending
   - Approved
   - Processing
   - On Shipping
   - Shipped
   - Canceled
   - Completed

#### Updating Order Status
1. Click on an order
2. Click **Update Status** button
3. Select new status from the visual cards
4. Click **Update Status** to confirm

#### Assigning Delivery Personnel
1. Open an order
2. Click **Assign Delivery Man**
3. Select delivery person from the list
4. Delivery person will be notified

### Coupon Management

#### Creating a Coupon
1. Go to **Marketing** > **Coupons**
2. Click **Add New Coupon**
3. Configure coupon settings:
   - Coupon code
   - Discount type (Percentage / Fixed amount)
   - Discount value
   - Minimum order amount
   - Valid period (start and end date)
   - Usage limits (total uses, per user)
4. Select applicable products (optional)
5. Click **Save Coupon**

#### Viewing Coupon Details
- Click on any coupon to view:
  - Discount value and type
  - Validity period
  - Usage limits
  - Applied products
  - Current usage statistics

### Discount Management

#### Creating a Discount
1. Navigate to **Marketing** > **Discounts**
2. Click **Add New Discount**
3. Set discount parameters:
   - Discount name
   - Discount value and strategy
   - Scope (Product, Category, Brand)
   - Promotion type
   - Valid dates
   - Status (Active/Inactive)
4. Upload discount image
5. Save the discount

### User Management

#### Managing Users
1. Go to **Users** > **All Users**
2. View list of all registered users
3. Filter by role (Customer, Vendor, Admin, Delivery Man)
4. Edit user details or change roles
5. Deactivate or activate users

#### Adding New Users
1. Click **Add New User**
2. Fill in user information
3. Assign appropriate role
4. Set permissions
5. Send invitation email (optional)

### Content Management

#### Managing Blogs
1. Navigate to **Content** > **Blogs**
2. Create new blog posts
3. Organize posts with categories
4. Manage comments and engagement

#### Menu Management
- Configure header, footer, and topbar menus
- Add/remove menu items
- Set menu hierarchy
- Link to pages, categories,or custom URLs

### Settings

#### General Settings

**Site Settings:**
- Site name and description
- Logo and favicon
- Contact information
- Social media links

**Currency Settings:**
- Default currency
- Currency symbol
- Exchange rates (if multi-currency)

**Shipping Settings:**
- Shipping methods
- Shipping zones
- Flat rate or calculated shipping
- Free shipping threshold

**Tax Settings:**
- Tax rates
- Tax calculation method
- Tax display preferences

#### Geo-Location Sync
1. Go to **Settings** > **Sync Geo-Location**
2. Click **Sync Geo-Location Data**
3. Wait for the sync to complete
4. This updates countries, states, and cities database

### Notifications

#### Managing Notifications
- View all notifications in the **notification dropdown**
- Mark notifications as read
- Filter by notification type
- Configure notification preferences

## Troubleshooting

### Common Issues

#### Cannot Log In
- Verify email and password are correct
- Check if account is activated
- Try password reset if needed
- Clear browser cache and cookies

#### Payment Failed
- Check internet connection
- Verify payment details
- Ensure sufficient balance/credit
- Try alternative payment method
- Contact support if issue persists

#### Order Not Showing
- Check if order was successfully placed
- Look in spam/junk for order confirmation email
- Wait a few minutes and refresh
- Contact customer support with order details

#### Coupon Not Working
- Verify coupon code is correct
- Check coupon validity period
- Ensure minimum order amount is met
- Confirm coupon usage limit not exceeded
- Check if coupon applies to your cart items

#### Product Out of Stock
- Check product page for restock date
- Enable stock notifications (if available)
- Contact seller for availability
- Look for similar products
